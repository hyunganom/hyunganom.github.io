# 이현재 GitHub Pages 이력서 & 포트폴리오

GitHub Pages 배포용 정적 웹사이트입니다.

## 포함 페이지

- `/` : 웹 이력서
- `/portfolio/` : 포트폴리오 목록
- `/portfolio/thermal-safety/` : 열화상·가스 안전관제 시스템
- `/portfolio/city-signal/` : 도시 교통신호 최적화 시스템
- `/portfolio/thermal-parking/` : 열화상 주차 감지 CV 알고리즘

## PDF 출력

각 상세 페이지에는 `브라우저에서 PDF 저장` 버튼이 있습니다.
또한 `assets/html-pdf/` 폴더에 HTML 기준으로 미리 출력한 PDF 파일을 포함했습니다.

## 배포 방법

압축을 푼 뒤 ZIP 파일 자체가 아니라 내부 파일 전체를 GitHub 저장소 루트에 업로드하세요.

## 연구과제 포트폴리오

- /portfolio/ev-fire-research/ : 한국도로공사 전기차 전소실험 공동 연구과제 — 실험 방법, 경보 결과, 연구 참여 범위
- assets/ev-fire-research/ : 첨부 자료에서 추출한 사진·원본 그래프와 재구성한 SVG 도식
